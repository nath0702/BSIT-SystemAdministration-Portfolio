# Challenges Encountered

- **Python PATH and Virtual Environment Problems**
    - Python or its packages were not always recognized correctly because of PATH and environment configuration.
    - I checked the Python installation and verified the Python version through the terminal.
    - I learned how to create and activate Python virtual environments and select the correct Python interpreter.
- **PowerShell Execution Policy**
    - PowerShell prevented some Python virtual-environment scripts from running.
    - I identified that the problem was caused by PowerShell's execution policy.
    - I adjusted the development environment and used the appropriate terminal configuration so the virtual environment could be activated.
- **Development Dependencies and Configuration**
    - Setting up C++, Qt, CMake, and vcpkg required several dependencies and configuration steps.
    - I checked the required compilers, SDKs, packages, and environment variables.
    - I configured the development tools step by step and verified that the components worked together.
- **Flask Static Files**
    - One of my Flask projects returned `404 Not Found` errors for files such as `dashboard.css` and `logo.png`.
    - I checked the project's folder structure and Flask's `static` directory.
    - I corrected the static-file locations and references so Flask could properly serve the CSS and image files.
- **MySQL and XAMPP Configuration**
    - I encountered configuration issues while working with MySQL, SQLyog, and XAMPP.
    - I checked whether the MySQL service was running and verified the database connection settings.
    - I corrected the configuration so the application could communicate with the database properly.
